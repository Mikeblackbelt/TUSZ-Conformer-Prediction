# TUSZ-Conformer-Prediction

Multi-task causal EEG Conformer for seizure prediction, timing estimation, and classification on the Temple University Seizure (TUSZ) corpus.

This repository implements a 3-head Causal EEG Conformer architecture paired with an optimized PyTorch DataLoader package (`dataset/` and `dataset_loader.py`) designed for fast reading of preprocessed Parquet session arrays generated by `Tuh-Preprocess`.

## Pipeline Overview

The full framework consists of two coupled repositories:

1. **`Tuh-Preprocess`**: Builds the annotation dataset (`master_full.csv`), generates preictal/postictal/consecutive/background intervals, resamples/filters EEG signals, and extracts multi-channel Parquet session checkpoints with file sample offset tracking (`_offsets.json`).
2. **`TUSZ-Conformer-Prediction`**: Loads session arrays using session-grouped batching, runs a Causal Conformer backbone, and trains multi-task heads for horizon token generation, seizure occurrence/timing prediction, and seizure type classification.

```
Tuh-Preprocess (Raw EDFs & CSVs)
   └── pipeline_gpt2class.py
         ├── preictal_segment.py (Master CSV, p*, q*, c*, x*, bg* labels)
         ├── raw_eeg_extraction.py (256 Hz resampling, bandpass/notch filtering)
         └── checkpoint_io.py (.parquet session arrays & _offsets.json)
               │
               ▼
TUSZ-Conformer-Prediction
   ├── dataset/ (SessionBatchSampler, PyArrow -> NumPy, O(1) offsets)
   ├── models/ (Causal EEG-Conformer backbone)
   │     ├── Task 1: Horizon Next-Token Generator
   │     ├── Task 2: Seizure Occurrence (IF) & Relative Timing (WHEN)
   │     └── Task 3: Seizure Type Classifier
   └── training/ (Multi-task loss formulation, Focal loss, Trainer & Metrics)
```

## Architecture (`models/`)

`CausalEEGConformer` inputs multi-channel EEG windows of shape `(batch_size, n_channels, n_samples)`:

* **Convolutional Front-End** (`models/blocks.py`): Extracts spatial and temporal token embeddings using depthwise and separable 1D convolutions.
* **Causal Transformer Encoder** (`models/blocks.py`): Applies causal self-attention masks across sequence tokens to prevent future step leakage.
* **Multi-Task Heads** (`models/heads.py`):
  * **Task 1 (Horizon Generator)**: Predicts future EEG token embeddings across the preictal-to-ictal horizon.
  * **Task 2 (Occurrence & Timing)**: Predicts `occurrence` (binary logits for seizure activity) and `onset_offset` (normalized relative time to seizure onset in `[0, 1]`).
  * **Task 3 (Seizure Classifier)**: Multi-class logits for specific seizure types (`fnsz`, `gnsz`, `cpsz`, `absz`, etc.) or background.

## Data Loading Performance (`dataset/`)

The `dataset/` package implements several optimizations for loading window slices from disk arrays without GPU idle time:

* **`SessionBatchSampler`** (`dataset/samplers.py`): Groups sample indices by session key within each batch while shuffling session order and intra-session window order per epoch. This keeps consecutive reads within the active LRU cache session, achieving ~99% cache hits and reducing per-epoch file reads from ~50,000 to ~500.
* **Direct PyArrow to NumPy Loading** (`dataset/io.py`): `_load_parquet_array()` converts `.parquet` columns directly into NumPy float32 arrays without creating intermediate Pandas DataFrames.
* **O(1) Session Offsets Mapping** (`dataset/io.py`): Multi-file EDF sessions are mapped via pre-indexed path/basename dictionaries in `_OFFSETS_CACHE`.
* **Explicit Label Classification & Filtering** (`dataset/label_utils.py`): Categorizes raw annotation tags into `background`, `preictal`, `ictal`, or `excluded` with fail-loud validation.
* **Safe Status Parsing** (`dataset/dataset.py`): `status` values (`-1` original, `1` valid generated, `2` collapsed) are parsed with `pd.notna()` checks to prevent NaN conversion errors in DataLoader workers.

## Training (`train.py` or `training/cli.py`)

Run multi-task training with default session batching and LRU caching:

```bash
python train.py \
  --master-csv /path/to/master_full.csv \
  --checkpoint-dir /path/to/checkpoints \
  --stage proc \
  --batch-size 64 \
  --epochs 20 \
  --lr 5e-4 \
  --cache-capacity 128 \
  --num-workers 4 \
  --output-dir ./runs/exp1
```

### CLI Options

| Argument | Default | Description |
| :--- | :--- | :--- |
| `--master-csv` | *(Required)* | Path to `master_full.csv` generated by `Tuh-Preprocess`. |
| `--checkpoint-dir` | *(Required)* | Directory containing `.parquet` session checkpoints. |
| `--stage` | `proc` | Stage to load: `proc` (bipolar montage) or `raw`. |
| `--batch-size` | `32` | Training batch size. |
| `--epochs` | `10` | Total training epochs. |
| `--lr` | `5e-4` | Learning rate. |
| `--cache-capacity` | `128` | Number of session arrays held in RAM LRU cache. |
| `--num-workers` | `4` | DataLoader worker processes. |
| `--no-session-batching` | `False` | Disables `SessionBatchSampler` (reverts to standard random draws). |
| `--exclude-labels` | `bckg` | Comma-separated labels to exclude (default drops artifact-flagged `bckg`). |
| `--timing-norm-seconds` | `300.0` | Normalization factor in seconds for relative onset target (`WHEN`). |
| `--horizon-tokens` | `10` | Number of horizon tokens generated by Task 1 head. |
| `--horizon-gate-threshold` | `0.01` | Curriculum threshold for exposing generated horizon tokens to Tasks 2 and 3. |
| `--use-focal-loss` | `False` | Enables Focal Loss (FocalBCE and FocalCrossEntropy). |
| `--focal-gamma` | `2.0` | Focal loss focusing parameter gamma. |
| `--no-compile` | `False` | Disables `torch.compile()`. |
| `--no-amp` | `False` | Disables FP16/BF16 Automatic Mixed Precision. |

## Outputs & Validation

`train.py` logs per-epoch loss breakdowns:
* `Gen Loss`: Next-token generator MSE.
* `Horizon Loss`: Real-EEG ground-truth horizon supervision loss.
* `Occ Loss`: Seizure occurrence BCE loss (class-weighted or focal).
* `Timing Loss`: Relative onset offset Smooth L1 loss.
* `Type Loss`: Seizure type Cross-Entropy loss (balanced weights or focal).

Upon completion, `train.py` computes a validation confusion matrix and reports per-class Precision, Recall, F1, and Support metrics. Checkpoints are saved to `best.pt` (tracked by best validation Macro-F1) and `epoch_XX.pt`.
